# CHALUPA! — 32 prémiových rastrových ilustrací

**Výtvarný stav:** Kompletní rastrová edice v uživatelem schváleném výtvarném směru. Každý asset má vlastní obrazové generování a kompozici.

Prémiový český letní komiks: expresivní dospělé postavy, pohyb, materiály a skutečné stínování. Rajčatová zahrada, mechový les, tyrkysový rybník a slunečné plátno výprav.

Silueta před drobností, dospělý hravý humor před nostalgií. Každý svět má předmět, tvora i obyvatele; nejde jen o sbírku veselých rekvizit.

Každý svět má samostatný suit symbol. Původní herní suits a pravidla se nemění.
Temné inkousty slouží indexům, světlejší akcenty velkým plochám ilustrací a dekoraci.

Q = Kapitán, K = Boss, A = Esence. J/Q/K jsou individuální postavy nebo entity,

## Assety a integrace

- 32 transparentních WebP s max. hranou 768 px, 32px bezpečnostní okraj: `packages/web/public/decks/chalupa/stickers/{suit}-{rank}.webp`. Bez textu, hodnot, indexů a bez líce karty.
- Rub: `packages/web/public/decks/chalupa/back.svg`, 200 × 280 se značkou BALÍK.
- Manifest: `packages/web/src/themes/decks/chalupa/manifest.json`.
- Autoritativní manifest rastrové edice: `packages/web/src/themes/decks/chalupa/premium-manifest.json`. Opětovné `art:worlds` jej zachová.
- Veřejná galerie: `/decks/chalupa` — skutečný CardView, filtr, detail, malé karty, světlý/tmavý podklad, ruby.
- Stůl **Letní večer** je nezávisle volitelná decentní paleta stávajícího BALÍK aparátu.
- Preference zůstává lokální v `balik.appearance`. Žádné nové herní ani síťové údaje.

Obrázky: built-in image_gen, jeden prompt na kartu. Přesné prompty a původní lokální PNG: `docs/visual/premium-series/generated/`. Kompoziční zadání: `scripts/art/premium-directions.mjs`. Export používá pouze alpha crop, padding, resampling a WebP encoding; nic nedokresluje.

## Čitelnost a principy

[Přehled 32 skutečných ilustrací](premium-series/chalupa-contact.png) · [48px miniatury](premium-series/chalupa-small.png)

CardBase, indexy, sticker a FX zůstávají oddělené. Velké siluety a hodnotové skupiny
mají přednost před mikrotexturou. Materiál, konstrukce, gesto a kompozice nesou
výtvarnou kvalitu; validita souboru ani počet motivů ji samy neprokazují.

Původní SVG zůstávají pouze jako archiv pracovních studií. Runtime používá všech 32 WebP, nikoli směs SVG a rasteru.

Dekorativní efekty zachovávají stávající časování a reduced motion. Samostatný
papírový flutter není implementován. Tisková sazba a barevný profil nejsou součástí webových assetů.
