# Strašidla — 32 původních bytostí

Světy: Oheň (hearts), Noc (diamonds), Les (clubs), Voda (spades). Engine se nemění.
Role: 7 útočí, 10 nese poklad (body), J je strašidýlko, Q nese bludnou lucernu (mění barvu), K je pán světa, eso je předmět, který zastaví hru.
